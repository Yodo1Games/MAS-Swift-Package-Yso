# Yodo1 MAS iOS SDK - Yodo1MasMediationYso

Yodo1 MAS (Managed Ad Services) iOS SDK for Swift Package Manager.

This repository is written by the MAS SDK release pipeline. Every published
version carries its own `Package.swift`, sources and integration instructions;
add the package URL in Xcode (File -> Add Package Dependencies) and pin the
version tag you need.

- Package URL: https://github.com/Yodo1Games/MAS-Swift-Package-Yso.git
- Requirements: iOS 15.0+, Swift tools 5.6+, Xcode (tested with) 26.1.1

Integration instructions for the current release are included in the README
of that release tag.
